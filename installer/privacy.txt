Privacy

Snowy works offline, with these exceptions:

1. Update check. Once a day Snowy asks the GitHub API (api.github.com) whether a newer release exists. This is on by default and can be turned off in Settings > System > Check for updates. The request contains only the app name and version (User-Agent: Snowy/<version>) plus your IP address, like any web request. Updates are only downloaded if you accept them.

2. "Match my weather" (optional). Only when you choose this feature, Snowy looks up your rough location from your IP address (ip-api.com, falling back to ipapi.co) and then fetches the current weather for those rounded coordinates from Open-Meteo (api.open-meteo.com).

3. Anonymous usage count. Once a day Snowy sends only its version number to snowy.berkcantumer.dev, so we can count how many people use Snowy. This is on by default and can be turned off in Settings > System > Send anonymous usage count. The server only adds the version to that day's totals; it keeps no IP addresses and nothing that identifies you.

4. Friends (optional, off unless you turn it on in Settings > Friends). When on, Snowy creates a key pair on your computer and connects to snowy.berkcantumer.dev. The server stores your public key, the friend code derived from it, your friendships and pending friend requests. Nicknames you give friends stay on your computer. No IP addresses are stored.

Snowy has no analytics and no accounts. Nothing else is sent anywhere.
