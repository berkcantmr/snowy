## What's new

- **Friends.** Turn on Friends in Settings, share your code, and add friends with theirs. You see when they are online. No account, no e-mail: each computer makes its own key.
- **Snowballs and gifts for friends.** Throw a snowball onto a friend's desktop (it falls in from the top while it snows) or send a gift that floats down on a parachute. A short notice says who it was. You can turn snowballs or gifts off per friend, and both are rate-limited.
- **A shared desktop.** Invite a friend to share decorations: you both see the same trees, snowmen and lights on your main screens and every move shows up on the other side. When sharing ends, each of you gets your own decorations back.
- **Snowballs bump into each other.** Flying snowballs bounce off one another, knock resting ones along the snow, and burst on a hard hit.
- **End-to-end encrypted.** Everything friends send each other is encrypted on the sender's computer; the friends server only passes it along and can't read it.

## Privacy

- **Anonymous usage count** (on by default, Settings > System): once a day Snowy sends only its version number so the number of users can be counted. Nothing identifies you, and the server keeps only daily totals.
- **Friends** stay off until you turn them on. The installer's privacy notice and the README list exactly what is stored.

## Install

Download `Snowy-0.1.6-setup.exe`, or use the portable zip. Installed copies offer this update from the tray menu. The `.sha256` file next to the installer holds its checksum.
