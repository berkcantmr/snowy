## What's new

- **Name your snowmen.** Each snowman's editor has a Name field. The name is only shown there, never on the desktop.
- **Snowballs press into the snow.** A resting snowball sinks in by its size (bigger ones deeper) and pushes up a small rim of snow around it, without slowly sinking through.
- **A clear desktop for arranging.** Edit mode (Win + Alt + S) hides the desktop icons while you arrange decorations and brings them back when it ends, times out, or Snowy quits. If the icons were already hidden, Snowy leaves them alone.

## Fixes

- **Taskbar menus stay above the snow.** The taskbar's right-click menu, context menus, the tray overflow, thumbnails, and Start/search are no longer covered by snow on the taskbar edge.
- **Friends page fits narrow windows.** Buttons wrap instead of pushing the card off the window, and long names get their own line.

## Install

Download `Snowy-0.1.7-setup.exe`, or use the portable zip. Installed copies offer this update from the tray menu. The `.sha256` file next to the installer holds its checksum.
