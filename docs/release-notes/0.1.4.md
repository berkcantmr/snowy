## What's new

- **A "What's new" window.** After an update, Snowy shows the highlights of the new version once, with pictures. You can close it right away.
- **Windows fit every display scale.** Settings, the snowman editor and the new window open inside the screen at 125 %, 150 % and 175 % scaling, never under the taskbar, and get their size back if a scale change squashed them.
- **Leftover windows close with Snowy.** Settings and editor windows close by themselves when Snowy quits.
- **MIT License again.** Snowy is open source under the MIT License from this version on.
- **Privacy notice in the installer.** The installer shows what Snowy sends over the network (an update check, and the weather lookup if you turn it on) before installing.
- **Built by GitHub Actions.** Release files are now built from the public source on GitHub Actions.

## Install

Download `Snowy-0.1.4-setup.exe`, or use the portable zip. Installed copies offer this update from the tray menu. The `.sha256` file next to the installer holds its checksum.
